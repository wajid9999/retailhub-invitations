# Inviteora Normal Wedding — Emerald Mughal

Package built to match the repository's existing `.github/workflows/pages.yml` contract.

Required files:
- `template.json`: unique catalog metadata
- `template.html`: complete five-slide bilingual invitation
- `thumbnail.svg`: gallery thumbnail

Slides: Bismillah/invitation; bride and groom with parents; date and time; venue with Google Maps search link; hosts and dua.

Controls: Urdu/English toggle, autoplay, pause, next/previous, dots, and touch swipe.

This is a draft package in the isolated `video-studio-lab` branch. Sample names, date, venue, and host names are placeholders. The visual uses CSS-based emerald/gold Mughal framing; the approved ornate image-backed artwork remains a separate preview asset and is not yet included in this repo package.
