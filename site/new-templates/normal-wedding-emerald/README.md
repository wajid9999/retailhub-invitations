# Inviteora Normal Wedding — Emerald Mughal

Package built to match the repository's existing `.github/workflows/pages.yml` contract.

Required files:
- `template.json`: unique catalog metadata
- `template.html`: complete five-slide bilingual invitation
- `thumbnail.svg`: finished gallery thumbnail matching the artwork\n- `media/emerald-mughal-background.svg`: ornate 9:16 emerald Mughal artwork used by the HTML

Slides: Bismillah/invitation; bride and groom with parents; date and time; venue with Google Maps search link; hosts and dua.

Controls: Urdu/English toggle, autoplay, pause, next/previous, dots, and touch swipe.

This is a draft package in the isolated `video-studio-lab` branch. Sample names, date, venue, and host names are placeholders. The visual uses a dedicated SVG artwork asset with a Mughal arch, gold filigree, lanterns, floral corners, and palace silhouette. No curtains or curtain-opening animation are used.
