# Inviteora Video Lab — Test 01

This is an isolated draft experiment on the `video-studio-lab` branch. It does not modify the live invitation templates or the VIP project.

## Test
- Format: vertical 9:16
- Style: simple cinematic product promo (not a wedding invitation)
- Motion: animated light glow and title entrance
- Controls: replay animation
- Audio: not included in this first visual test
- Export: HTML preview only; MP4 rendering is not wired up yet

## Why this test exists
First verify that the HTML-based visual approach can create a clean, timed vertical scene. Next, evaluate the `nexu-io/html-video` rendering workflow (Chromium + ffmpeg) separately and connect it only after the basic visual test is approved.

## Safety / publishing
Keep this branch as a draft. Do not merge it into `main` or add it to the live gallery until reviewed.
